**Cipher Host** is a privacy-first, open-source managed WordPress
hosting company built from the ground up.

We run our business with radical transparency and zero corporate
nonsense, focusing on what actually matters: rock-solid hosting, genuine
privacy, and treating customers the way we'd want to be treated.

No venture capital, no data harvesting, no marketing fluff—just honest,
privacy-respecting WordPress hosting done right.

## Community

We believe in building in public and giving back to the open-source
community. We welcome privacy-conscious developers, designers, and
anyone passionate about making the web more secure and private.

Want to contribute? Check out our [Contributing
Guidelines](https://github.com/cipherdothost/.github/blob/trunk/CONTRIBUTING.md)
to get started. All community participation is governed by [our Code of
Conduct](https://github.com/cipherdothost/.github/blob/trunk/CODE_OF_CONDUCT.md).
